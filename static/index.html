Deepfake Detection System: Hybrid Spatial-Temporal Forensics

Generative Adversarial Networks (GANs), diffusion models, and neural face-swapping tools have made hyper-realistic synthetic media accessible to anyone. While existing forensic detectors rely on heavy 3D Convolutional Neural Networks (3D-CNNs) or Vision Transformers that require expensive server-grade GPUs, our system introduces a cloud-trained, CPU-deployed hybrid architecture capable of verifying both static images and video sequences in under two seconds on a standard laptop.

1. Decoupled Compute

Trained on cloud Tesla T4 GPUs and compressed into a ~6 MB PyTorch state dictionary for instant local CPU execution.

2. Dual-Domain Learning

Jointly learns high-frequency GAN upsampling artifacts from images and face-swap blending boundaries from compressed MP4 videos.

3. Zero Data Retention

All uploaded media is processed inside volatile temporary buffers and purged immediately after inference completes.

End-to-End Methodology

How the Detection Engine Works

STAGE 01

Media Ingestion

FastAPI validates MIME headers for images (JPG, PNG) and videos (MP4, AVI, MOV) via async streaming.

STAGE 02

Keyframe Sampling

OpenCV extracts up to 36 uniformly spaced frames across the video timeline using linear index interpolation.

STAGE 03

Face ROI Cropping

Haar-Cascade frontal face detection isolates the largest facial bounding box and resizes it to 224×224 RGB.

STAGE 04

CNN Analysis

MobileNetV3-Small inverted residual blocks inspect pixel-level blending artifacts.

STAGE 05

Aggregation

Softmax probabilities and cross-frame variance are averaged to output the final REAL/FAKE confidence.

Training Corpus

Balanced Multi-Domain Datasets

To prevent class bias and domain overfitting, our training pipeline merges static portrait datasets with real-world video sequences at an exact 50% Real / 50% Fake ratio:

140k Real and Fake Faces

Image Domain

Combines real human photographs with synthetic faces generated by StyleGAN. Teaches the model to spot unnatural skin pore smoothing and background hair artifacts.

Deep Fake Detection (DFD) & FaceForensics++

Video Domain

Contains original actor recordings alongside neural face-swapped sequences. Grouped strictly by video ID before splitting so the test set evaluates completely unseen subjects.
